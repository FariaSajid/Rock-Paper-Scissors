# ✊ ✋ ✌️ Rock Paper Scissors Game (C++)

Welcome to the **Rock Paper Scissors** repository! This project is a fun, interactive console-based implementation of the classic hand game written in C++, allowing players to test their luck and strategy against the computer.

🌐 **Repository Link:** [https://github.com/FariaSajid/Rock-Paper-Scissors](https://github.com/FariaSajid/Rock-Paper-Scissors)

---

## ✨ Features

- **Interactive Gameplay:** Play rounds of Rock, Paper, Scissors directly from your terminal.
- **Computer AI:** Automated computer choice generation using pseudo-random number generation.
- **Score Tracking:** Keeps a running tally of wins, losses, and ties throughout the game session.
- **Input Validation:** Handles user inputs robustly to prevent crashes from invalid choices.

---

## 🛠️ Tech Stack & Concepts

- **Language:** C++
- **Key Concepts:**
  - Control flow (`switch` statements, `if-else` conditions, loops)
  - Random number generation (`<cstdlib>` and `<ctime>`)
  - User input handling and validation
  - Game state and score management
